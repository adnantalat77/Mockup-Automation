# Project: Mockup-Automation
## Equipd Wear — Shopify Product Mockup Automation Manager

### 1. Project Overview

I am developing a custom web-based application called **Mockup-Automation** for my Shopify apparel store, **Equipd Wear**.

Equipd Wear sells print-on-demand apparel, including T-shirts featuring designs from collections such as Texas Heritage, National Parks, and Outdoors & Adventure.

We use **Shopify** as our e-commerce platform and **Printful** as our print-on-demand supplier.

The purpose of this application is to automate the creation and publishing of professional product mockup images by placing existing transparent Printful shirt images over custom background images.

**The application must never modify the actual shirt, its printed design, color, texture, or appearance.**

The only intended image transformation is placing a custom background behind the original transparent product image.

### 3. Core Application Workflow

The application must support the following workflow.

**Step 1 — Search Shopify Product**

- Provide a text input where I can enter the exact Shopify product title.
- Search the Equipd Wear Shopify catalog using the Admin GraphQL API.
- Display matching products if more than one result is found.
- Allow me to select the correct product.
- Retrieve the product's existing images, variants, colors, sizes, and image associations.

**Step 2 — Retrieve Existing Product Mockups**

- Load the original product mockup images supplied by Printful.
- Determine which images correspond to each shirt color.
- Identify unique mockups shared by multiple size variants.
- Avoid generating duplicate images for different sizes when the source mockup is identical.
- Verify whether each source PNG contains a transparent alpha channel.
- If an image is not transparent, display a warning rather than silently modifying the shirt.

**Step 3 — Upload Background Image**

- Provide an interface for uploading a background image from my computer.
- Support PNG and JPEG backgrounds.
- Display a preview of the uploaded background.
- Allow reusable background images to be saved in a local background library.
- Use one selected background for every variant of the selected product.

Backgrounds may include rustic Texas scenes, national park scenery, camping equipment, or other lifestyle settings.

**Step 4 — Generate Product Mockups**

- Use Sharp to composite the original transparent shirt PNG over the selected background.
- Preserve the original shirt pixels, design, fabric details, and colors.
- Do not use generative AI to recreate or alter the garment.
- Do not recolor or distort the shirt.
- Preserve the shirt's aspect ratio.
- If necessary, position or uniformly scale the entire unchanged shirt image to fit the background composition.
- Do not crop the shirt.
- Produce high-quality images suitable for Shopify product listings.
- Preserve the original source images.

**Step 5 — Apply Background to All Variants**

This is a mandatory requirement.

When I select a product and background, the application must process every applicable product variant.

For example:

If a Bella+Canvas 3001 product has Black, White, Navy, Heather Gray, and Military Green color options, every color must receive the same selected background.

If each color has sizes S, M, L, XL, 2XL, and 3XL, the application should reuse the generated image for all sizes sharing the same color mockup.

Do not generate unnecessary duplicate images.

Maintain accurate relationships between Shopify variants and their corresponding images.

**Step 6 — Preview Before Publishing**

- Display a preview of every generated color mockup.
- Show the original and processed images for comparison.
- Indicate which variants will be affected.
- Display warnings for missing or incompatible source images.
- Require explicit user approval before making changes to Shopify.

**Step 7 — Publish to Shopify**

After approval:

- Upload the newly generated mockup images to the corresponding Shopify product.
- Associate each image with the appropriate product variants.
- Ensure selecting a shirt color displays the correct mockup.
- Allow the generated mockups to become the primary product images.
- Preserve the original Printful images for recovery.
- Do not delete the original product media automatically.
- Do not modify Shopify product pricing, SKUs, inventory, fulfillment settings, or Printful synchronization identifiers.
- Record publishing results and failures.
- Provide a rollback option to restore previous image associations.

Use supported Shopify Admin GraphQL API operations and verify their current availability before implementing them.

### 5. Technical Architecture

Use a modular architecture with clear separation between:

1. React frontend
2. Node.js API backend
3. Shopify API integration service
4. Image-processing service
5. Local background image storage
6. SQLite database
7. Publishing and rollback service

The backend must handle all Shopify credentials and authenticated API requests.

Never expose Shopify access tokens to the browser.

Use environment variables for secrets and exclude `.env` files from Git.

Implement proper error handling, logging, image validation, and Shopify API rate-limit handling.

Avoid relying on deprecated Shopify APIs.

### 6. Important Image-Processing Requirements

The original Printful mockup is the source of truth.

The application must not regenerate or modify the shirt using AI.

The shirt must remain visually identical to the original, except for permissible whole-image positioning and proportional scaling.

The compositing process must preserve transparency, avoid visible halos, and produce consistent results.

A PNG file does not automatically mean that it has a transparent background.

The application must inspect the actual alpha channel before processing.

If the original image contains a solid background, flag it as incompatible and request a suitable transparent source.

Do not automatically perform background removal in the initial version.
